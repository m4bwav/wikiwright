usage: wikiwright.py [-h] [--version]
                     {preflight,check,live,outputs,snippets,unbs,diffout,cachecheck,releasecheck,registry,scaffold}
                     ...

wikiwright helper: the mechanical half of writing a GitHub wiki.

positional arguments:
  {preflight,check,live,outputs,snippets,unbs,diffout,cachecheck,releasecheck,registry,scaffold}
    preflight           wiki feature, wiki repository, placeholder, clone
    check               lint a wiki working copy
    live                check the published pages
    outputs             every output a page shows appears in the verify output
    snippets            every code block a page shows is in the verification
                        program
    unbs                replace <BS> placeholders with backslashes
    diffout             compare two runs of a verification script, section by
                        section
    cachecheck          the installed plugin cache against the source, by
                        SHA-256
    releasecheck        version fields, CHANGELOG entry and a test run before
                        tagging
    registry            a compact registry survey of an npm or NuGet package
    scaffold            write the verification script, filled in and cut to
                        the sections needed

optional arguments:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
